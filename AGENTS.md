Project: UrbanFix

Backend:
- Spring Boot 3
- JWT Authentication
- Swagger available
- REST APIs are the source of truth

Frontend:
- React + Vite
- Material UI
- Axios
- React Router
- Recharts
- Responsive

Rules:
- Never invent API endpoints unless explicitly told in chat.
- Use only endpoints exposed by the backend/Swagger.
- Build feature by feature.
- Ensure the project compiles after every major change.
- Reuse components.
- Use Axios interceptors for JWT.
- Keep code production-ready.
